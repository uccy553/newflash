# **App Name**: FlashFlow

## Core Features:

- Flashcard Creation: User-friendly interface to create and edit flashcards with text and image uploads.
- Smart Scheduling: Spaced repetition algorithm to schedule flashcard reviews.
- Quiz Mode: Quiz mode for flashcard review and score tracking.
- Tag Suggestions: AI-powered tool that suggests tags for flashcards to aid in categorization and search.
- Scoreboard: Progress tracking dashboard to display quiz scores.

## Style Guidelines:

- Primary color: A calming blue (#3498db) for focus.
- Secondary color: A soft gray (#ecf0f1) for backgrounds.
- Accent: Green (#2ecc71) for success and positive feedback.
- Clean and readable sans-serif fonts to ensure legibility.
- Simple, intuitive icons to represent actions.
- Mobile-first, responsive design for use on any device.
- Subtle animations and transitions for a smooth user experience.
